# PRD: Dictionary Convert

## Описание проекта

Локальное веб-приложение для обработки словарных файлов. Принимает на вход один большой .docx файл со словарными статьями, разбитыми по алфавиту. На выходе — набор CSV-файлов по буквам, готовых для импорта в WordPress через плагин WP All Import.

## Технологический стек

- **Бэкенд:** Python + Flask (локальный сервер на localhost)
- **Фронтенд:** HTML + CSS + JavaScript
- **Обработка документов:** python-docx (чтение .docx), встроенный модуль csv (запись CSV)
- **Платформа:** Windows, работа только локально

## Архитектура

```
Браузер (localhost) <---> Flask-сервер <---> Python-скрипты (splitter, converter)
```

## Структура папок

```
new_dictionary/
├── app.py              # Flask-сервер, точка входа
├── splitter.py         # Логика разбиения .docx по буквам
├── converter.py        # Логика конвертации .docx → CSV
├── requirements.txt    # Зависимости Python
├── templates/          # HTML-шаблоны
│   └── index.html
├── static/             # CSS, JS
│   ├── style.css
│   └── script.js
├── input/              # Исходный .docx файл (загружается пользователем)
├── split/              # Промежуточные .docx файлы по буквам
└── output/             # Готовые CSV файлы по буквам
```

## Функциональные требования

### 1. Загрузка файла

- Пользователь загружает .docx файл через интерфейс
- Файл сохраняется в папку `input/`
- Принимаются только файлы формата .docx

### 2. Сплиттер (разбиение по буквам)

- Читает загруженный .docx файл из папки `input/`
- Определяет секции по заглавным буквам русского алфавита (А-Я, Ё, ѲѲ)
- Разбивает содержимое на отдельные .docx файлы по буквам
- Сохраняет результат в папку `split/`
- Сохраняет форматирование текста (жирный, курсив, подчёркивание, шрифт, размер, цвет)

### 3. Конвертер (DOCX → CSV)

- Читает .docx файлы из папки `split/`
- Извлекает словарные статьи: заголовок (первое слово) и содержимое с HTML-форматированием
- Обрабатывает римские цифры (I-X) как часть заголовка
- Формирует CSV-файлы по буквам
- Сохраняет результат в папку `output/`

#### Формат выходного CSV

- **Разделитель:** `;` (точка с запятой)
- **Кодировка:** UTF-8
- **Текстовые поля с HTML:** оборачиваются в двойные кавычки, внутренние кавычки удваиваются

**Колонки:**

| Колонка | Описание | Пример |
|---------|----------|--------|
| `articleid` | Порядковый номер записи внутри файла-буквы (начинается с 1 в каждом файле) | `1`, `2`, `3` |
| `articlecat` | Буква раздела словаря (заполняется автоматически) | `А`, `Б`, `Д` |
| `articletitle` | Заголовок словарной статьи (первое слово, заглавными буквами) | `ДААБАРИ I` |
| `articleintrotext` | Содержимое статьи в HTML-формате, обёрнутое в `<p>` | `"<p><span class=""italic"">юум . н.</span> ...</p>"` |

**Пример строки CSV:**
```
2;Д;ДАА II;"<p><span class=""italic"">част.</span> 1) <span class=""italic"">текст...</span></p>"
```

**HTML-разметка в содержимом:**
- `<span class="bold">` — жирный текст
- `<span class="italic">` — курсивный текст
- `<span class="bold italic">` — жирный курсив
- Всё содержимое обёрнуто в `<p>...</p>`

### 4. Режимы запуска

- **Кнопка "Сплит"** — запускает только разбиение по буквам
- **Кнопка "Конвертация"** — запускает только конвертацию в CSV
- **Кнопка "Запустить всё"** — последовательно выполняет сплит и конвертацию

### 5. Просмотр папок

- Кнопка открытия папки `input/` в проводнике Windows
- Кнопка открытия папки `split/` в проводнике Windows
- Кнопка открытия папки `output/` в проводнике Windows

### 6. Лог прогресса

- Область лога в интерфейсе с подробным отображением хода работы
- Сообщения на русском языке
- Примеры сообщений:
  - "Файл загружен: словарь.docx"
  - "Найдено 19 секций"
  - "Обработана буква А — 1913 записей"
  - "Конвертация завершена"
- Ошибки выделяются красным цветом и хорошо заметны в потоке лога
- Ошибки не должны теряться в потоке обычных сообщений

## Импорт в WordPress

- Используется плагин **WP All Import** (https://www.wpallimport.com/)
- Плагин поддерживает CSV, Excel, XML
- Маппинг колонок на поля WordPress выполняется через drag&drop интерфейс плагина
- Плагин автоматически определяет разделитель CSV

## Требования к интерфейсу

- Минималистичный, аккуратный дизайн
- Скруглённые элементы, без угловатости
- Язык интерфейса — русский (допустимы отдельные английские термины на кнопках)
- Лог прогресса — русский язык
- Интерфейс открывается в браузере по адресу localhost

## Ограничения и допущения

- Приложение работает только локально, размещение в интернете не планируется
- Состояние между сессиями не сохраняется — каждый раз новый цикл обработки
- Пользователь самостоятельно очищает папки `split/` и `output/` при необходимости
- Файлы перезаписываются при повторном запуске
