# Dictionary Convert

Локальное веб-приложение для обработки бурятско-русского словаря. Принимает на вход .docx файл со словарными статьями, разбитыми по алфавиту, и конвертирует их в набор CSV-файлов, готовых для импорта в WordPress через плагин WP All Import.

## Возможности

- **Сплит** — разбиение большого .docx файла на отдельные файлы по буквам алфавита (включая буквы бурятского алфавита: Ө, Ү, Һ)
- **Конвертация** — преобразование .docx файлов в CSV с сохранением форматирования (жирный, курсив) в виде HTML-разметки
- **Полный цикл** — последовательное выполнение сплита и конвертации одной кнопкой
- **Лог в реальном времени** — отображение хода обработки через Server-Sent Events
- **Открытие папок** — быстрый доступ к рабочим папкам из интерфейса

## Формат выходного CSV

| Колонка | Описание | Пример |
|---------|----------|--------|
| `articleid` | Порядковый номер записи (с 1 в каждом файле) | `1`, `2`, `3` |
| `articlecat` | Буква раздела | `А`, `Б`, `Ү` |
| `articletitle` | Заголовок статьи | `ДААБАРИ I` |
| `articleintrotext` | Содержимое в HTML-формате | `<p><span class="italic">текст</span></p>` |

- Разделитель: `;`
- Кодировка: UTF-8

## Технологии

- Python 3, Flask
- python-docx (чтение .docx)
- HTML + CSS + JavaScript (фронтенд)

## Установка

1. Клонировать репозиторий:

```bash
git clone https://github.com/ManGo-WEB/dictionary_converter.git
cd dictionary_converter
```

2. Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Приложение запустится на `http://127.0.0.1:5000/`. Откройте этот адрес в браузере.

## Использование

1. **Загрузите файл** — нажмите на область загрузки, выберите .docx файл словаря, нажмите кнопку «Загрузить»
2. **Выберите действие:**
   - **Сплит** — разбить файл на отдельные .docx по буквам (результат в папке `split/`)
   - **Конвертация** — конвертировать split-файлы в CSV (результат в папке `output/`)
   - **Запустить все** — выполнить сплит и конвертацию последовательно
3. **Следите за логом** — ход обработки отображается в области лога в нижней части страницы
4. **Откройте результат** — нажмите «Открыть output» для доступа к готовым CSV-файлам

## Импорт в WordPress

1. Установите плагин [WP All Import](https://www.wpallimport.com/)
2. Загрузите CSV-файл из папки `output/`
3. Настройте маппинг колонок на поля WordPress через интерфейс плагина

```
├── templates/

├── static/

│   └── script.js       # Логика фронтенда
├── input/              # Исходный .docx файл
├── split/              # Промежуточные .docx по буквам
└── output/             # Готовые CSV файлы
```
